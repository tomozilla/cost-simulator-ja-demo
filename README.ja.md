# cost-simulator-ja-demo

[English](README.md) | 日本語

1か月の使用量を入れると、Supabaseの請求を**スペンドキャップON/OFFで並べて**見せる、小さな学習用デモです。キャップが守らない項目（Compute・PITR・独自ドメイン）も分かります。HTML + JavaScript だけ。サーバーも、キーも、Supabaseのプロジェクトも使いません。

> **個人の学習記録・非公式です。** どの会社の公式ツールでも、見積りでもありません。料金は2026-10-27に料金ページとドキュメントで読んだ値で、「守る／守らない」の分け方はドキュメント「Control your costs」に従っています。

Qiitaの2本の記事のコードです：請求書の読み方とスペンドキャップの手順編、このシミュレーターをつくったWebアプリ編。

英語版のコードが基本で、日本語のコメント・UIのコピーは [`ja/`](ja/) にあります。

## ファイル

| ファイル | 内容 |
|---|---|

| `app/index.html`, `app/app.js` | 画面 |

## 費用

- このページを動かすのは無料です。
- 画面の金額は**目安**：プラン代（Pro $25 / Team $599）、プロジェクトごとのCompute（月額でMicro $10〜XL $210、時間課金、有料プランに$10含まれる）、PITR（プロジェクトごと月$100・7日分）、独自ドメイン（月$10）、超過分の単価は `rates.json` のとおり。**自分の請求で確かめたのは1つだけ**：Micro Compute 478時間＝$6.42。税・その他のアドオンは含みません。

## 限界（必ず読んでください）

- キャップONのとき、ページは**固定の項目だけ**を表示し、「**使えなくなる項目**」を並べます。枠に達したときにサービスが実際にどうなるか（停止・読み取り専用・エラー）は表示できません（試していません）。
- Team：ドキュメントに「スペンドキャップはProプランのみ」とあり、使用量のページにも、Teamでは「超過分はすべて課金される」とあります。そのためTeamのときは、ON/OFFの2つではなく**合計を1つだけ**表示します（超過分は課金され、使えなくなることはない）。2026-10-27にドキュメントで読んだ内容で、**Teamの組織は自分では動かしていません**。
- ドキュメントによると、キャップには項目ごとの予算も通知もありません。通知のシミュレーションはしません。
